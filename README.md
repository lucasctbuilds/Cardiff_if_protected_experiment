# Cardiff, if protected

A 3D model of Cardiff: what today's heritage criteria would have protected in 1947, rebuilt where it was
lost, and what is planned next around Curran Road. Made by Lucas Collyer-Todd, 2026.

Open `index.html` through a web server (GitHub Pages works as it is). The page loads its data from `data/`.
